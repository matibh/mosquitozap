# MOSQUITO ZAP 🦟

Juego web de reflejos en primera persona, hecho con Three.js.

## Jugar localmente
Abrí `index.html` mediante un servidor local (por ejemplo, VS Code Live Server). Three.js se carga desde jsDelivr.

## GitHub Pages
1. Entrá en **Settings → Pages**.
2. En **Build and deployment**, elegí **Deploy from a branch**.
3. Seleccioná `main` y la carpeta `/ (root)).
4. Guardá. GitHub publicará el juego en `https://matibh.github.io/mosquitozap/`.

## Controles
- Mouse: apuntar.
- Click: aplastar mosquito.
- Espacio: golpe rápido.

## Mecánica
Sobreviví 60 segundos. Eliminá mosquitos cuando se posan en tus brazos. Cada picadura suma al contador; al llegar a cinco, termina la partida.
